# صدقة جارية

تطبيق ويب عربي على أرواح خالد شحاتة ابراهيم، حسن الشافعي، شحاتة ابراهيم، زينات عطية، نجية محمد. نسأل الله لهم الرحمة والمغفرة.

## التشغيل

يلزم Node.js 20 أو أحدث. لا يحتاج المشروع إلى تثبيت مكتبات.

```sh
npm run dev
```

افتح http://localhost:5173 في المتصفح. لا تفتح index.html مباشرة لأن التطبيق يستخدم JavaScript modules.

## الخصائص

- فهرس سور القرآن الـ114، بحث بالاسم أو الرقم، قراءة بالرسم العثماني وتغيير حجم الخط.
- حفظ موضع قراءة باختيار «حفظ الموضع» بجوار الآية.
- تلاوة مشاري العفاسي آية بآية، تنتقل تلقائيًا حتى نهاية السورة.
- أذكار بعد الصلاة وقبل النوم وأذكار يومية مع المصادر والعدادات.
- أدعية قرآنية ودعاء عام للمتوفين، مع التمييز بينهما.
- مسبحة تحفظ العدد محليًا ووضع ليلي وتصميم متجاوب.

## المحتوى والاتصال

نص القرآن يُجلب من https://api.alquran.cloud/v1/quran/quran-uthmani مع مصدر بديل على https://alquran.api.islamic.network. يُتحقق من وجود 114 سورة و6236 آية وتسلسل السور والآيات قبل العرض، ثم تُحفظ النسخة محليًا إذا سمح المتصفح. التحقق البنيوي ليس تدقيقًا حرفيًا مستقلًا للمصحف. النص يعرض كما يرجعه المصدر دون تعديل.

التلاوة من https://cdn.islamic.network وتتطلب اتصالًا بالإنترنت. ذاكرة النص محلية فقط؛ التطبيق قابل للتثبيت ويخزّن الواجهة بعد أول تحميل ناجح. الخطوط من Google Fonts مع خطوط بديلة. لا حسابات ولا تحليلات ولا إعلانات. عند منع التخزين قد لا يستمر حفظ التفضيلات.

مصادر الأذكار: صحيح مسلم 591 و597، صحيح البخاري 6318 و6324 و6405 و6406. يمكن مراجعتها على https://sunnah.com. الأعداد في المسبحة الحرة ليست توصية بعدد تعبدي محدد.

## الاختبار والبناء

```sh
npm test
npm run build
```

انشر مجلد dist على استضافة ملفات ثابتة. المسارات تعتمد على hash فلا تحتاج إعداد fallback. لم يُنشر التطبيق بعد. تعذّر التحقق الحي من API والصوت في بيئة الإنشاء بسبب قيود الاتصال؛ يلزم فحصهما في متصفح متصل قبل النشر العام.

للتثبيت على الهاتف استخدم رابط HTTPS ثم زر تثبيت التطبيق. للاختبار المحلي يعمل localhost. عند تعديل ملفات الواجهة حدّث إصدار ذاكرة التخزين في sw.js.
